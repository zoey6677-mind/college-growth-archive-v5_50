# 成长档案 · 大学生成长记录

一个面向大学生的**纯前端**成长档案应用：记录大学期间的校园活动、竞赛获奖、志愿服务、社会实践、学术科研、学生工作六大类经历，数据全部保存在浏览器本地（IndexedDB），支持 JSON 备份与恢复，并可通过 PWA 离线使用。

无需服务器、无需注册账号、零第三方依赖，克隆后用 Live Server 打开即可运行。

---

## 功能特性

### 五个视图

底部导航切换五个视图，顶栏统一提供「学年筛选」，切换后所有视图同步到该学年的数据范围。

| 视图 | 内容 |
|---|---|
| **概览** | 当前学年、经历总数、六大分类概览、各学年分布、最近新增 |
| **经历** | 经历列表，支持分类筛选（带数量）、关键词搜索、按日期倒序；点击进入详情 |
| **统计** | 4 个关键指标、六大分类占比、各学年分布（CSS 条形图，未知分类自动兜底，不丢记录） |
| **时间轴** | 按年月分组倒序展示经历，点击复用经历详情 |
| **我的** | 学年管理（新增 / 重命名 / 迁移经历 / 删除）、数据备份与恢复 |

### 六大经历分类

校园活动、竞赛获奖、志愿服务、社会实践、学术科研、学生工作。新增经历时按所选分类动态显示专属字段（如竞赛的获奖等级与级别、志愿服务的时长与内容、科研的项目类型与链接等）。

### 经历与附件

- **新增**：表单保存前校验分类、名称、开始日期、结束日期（须为真实存在的日期，且不早于开始日期）、关联学年
- **查看**：详情页展示全部已填字段，并内联预览照片与证书
- **删除**：二次确认后，在同一个数据库事务中级联删除该经历及其全部附件
- **附件**：照片与证书上传时用 Canvas 压缩（最长边 1600px、JPEG 质量 0.82），以 Blob 形式存入 IndexedDB

### 学年管理

- 新增与重命名（名称必填、不允许重名）
- **有经历的学年禁止直接删除**；提供「把该学年经历迁移到其他学年」的功能，迁移成功后才允许删除原学年
- 迁移在单个事务内完成，避免出现半途失败导致数据不一致

### PWA 与离线

- `manifest.json` 提供应用名称、图标与独立窗口（standalone）配置
- Service Worker 预缓存全部静态资源（当前 35 项），安装成功即具备离线能力
- 导航请求采用网络优先、离线回退缓存首页；静态资源按类型分流（HTML/CSS/JS 网络优先，图标缓存优先 + 后台更新）
- 缓存按版本号隔离，升级时只清理本应用前缀的旧版本缓存

### 旧版数据迁移

首次运行时会检查旧版（v4）保存在 localStorage 中的数据，若存在且当前数据库为空，则自动迁移到 IndexedDB；迁移幂等、可重复调用，且保留原始 localStorage 数据不删除。

## 技术栈

| 层次 | 选型 |
|---|---|
| 页面结构 | 原生 HTML5 |
| 样式 | 原生 CSS3（自定义属性、Grid / Flex，移动优先） |
| 逻辑 | 原生 JavaScript **ES Modules**，无框架、无打包、无 npm 依赖 |
| 数据存储 | **IndexedDB**（数据库 `growth-archive`，version 1） |
| 离线能力 | Web App Manifest + Service Worker |
| 图片处理 | Canvas 压缩后以 Blob 入库 |

## 本地运行

本项目**没有构建步骤，也不需要安装依赖**，但必须通过 HTTP 访问——ES Modules、Service Worker、IndexedDB 在 `file://` 协议下均不可用。

1. 用 VS Code 打开项目根目录，安装 **Live Server** 扩展
2. 右键 `index.html` → **Open with Live Server**
3. 浏览器访问 `http://127.0.0.1:5500/`（默认端口 5500）
4. 首次打开会自动建库，控制台出现 `[SW v5-3] 预缓存成功 35/35` 表示离线资源已就绪

> **端口请保持不变**：IndexedDB 与 Service Worker 都按 origin 隔离，换成 `127.0.0.1:5501` 或 `localhost` 都会看到一份全新的空数据。

### 验证离线能力

DevTools → **Application** → **Service Workers**，勾选 **Offline** 后刷新页面，应用应正常显示并可浏览已保存的数据。

## 数据存储说明

所有数据仅保存在**当前浏览器**中，不上传任何服务器。

| Store | 主键 | 索引 | 说明 |
|---|---|---|---|
| `years` | `id` | `sortOrder` | 学年（名称、标签、排序） |
| `experiences` | `id` | `yearId`、`category`、`date`、`category`+`date` 复合 | 六大分类经历 |
| `attachments` | `id` | `experienceId`、`type` | 照片 / 证书，Blob 存储 |
| `meta` | `key` | 无 | 迁移标记等元数据 |

关联关系：`experiences.yearId → years.id`，`attachments.experienceId → experiences.id`。

## 备份与恢复

入口：**我的 → 数据备份与恢复**。

- **导出 JSON**：把学年、经历、附件导出为一个 JSON 文件，附件以 Base64 编码内嵌，可直接在本机保存
- **合并导入**：保留现有数据，与备份中 id 相同的记录跳过，只新增缺少的部分
- **覆盖恢复**：清空当前全部学年、经历和附件后用备份内容替换，操作前会二次确认，**不可撤销**

导入前会做完整校验：顶层结构、备份版本、分类合法性、名称、日期（严格校验，非法日期如 `2025-02-30` 会被拒绝）、学年引用是否存在等。任一致命问题都会让整次导入被拒绝，不会写入半成品数据。

### 数据安全提醒

**清除浏览器站点数据、使用隐私/无痕模式、更换浏览器或更换端口，都可能导致数据永久丢失。** IndexedDB 属于站点本地存储，不会被任何云端同步。请定期通过「导出 JSON 备份」保存副本，并把备份文件保存在自己的设备上。

## 已知限制

- **没有经历编辑界面**：数据模型层已支持更新，但界面暂未提供编辑入口，修改内容需删除后重新添加
- **没有账号与云同步**：数据仅存于本机浏览器，多设备之间不互通
- **`js/ui/charts/donut.js`、`js/ui/charts/bars.js` 是未使用的预留骨架**：当前统计页使用 CSS 条形图实现，这两个文件尚未被任何模块引用
